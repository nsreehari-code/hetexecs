Strategic Decision Records

Append-only, semantic. Each record captures a converged decision. New understanding = new record; old records are never edited.

Record Format

Four fields only:

id: dr-YYYY-MM-DD-NNN
timestamp: ISO 8601
source: Where the decision emerged (thread, meeting, conversation)
body: |
  Natural language carrying full meaning — claim, evidence,
  dissent, confidence, intent. No templates. No tags.

Properties

  • Semantic, not templated — meaning lives in the prose
  • Append-only, immutable — new understanding = new record
  • No status field — chronology is sufficient
  • No tags — agents search semantically
  • No participant list — trace back to source for provenance
  • No artifact links — agents discover state at query time

Routing

  • Strategic decisions → here (hetexecs/records/)
  • Operational decisions → hetops/records/
